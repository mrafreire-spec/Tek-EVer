# Moodle import artifacts

Both XML banks are draft practice material; not official examination items. In a disposable Moodle test course, open Question bank > Import > Moodle XML. Import each file into a separate category. Validate the item count, correct-answer distribution, feedback, source notes and regulatory currency before use. FAA material: Magnus Ullberg, MIT; see ../third-party/faa-drone-trainer/LICENSE (retain with exports). Do not deploy public practice items as secure examinations.

Regenerate with `node tools/export-moodle.cjs`. Format reference: https://docs.moodle.org/501/en/Moodle_XML . Actual Moodle import has not been run here.
