# Functional prototype scope

| Module | Demo capability | Production requirement |
| --- | --- | --- |
| Dashboard | Live metrics from fictional records | Server analytics |
| Learning | Read and mark lessons | Versioned delivery, identity |
| Syllabus | Search and filter draft mappings | Complete verified mapping |
| Question bank | Search, flag, simulated review | Secure review and access |
| Examinations | Randomized practice and scoring | Secure server assessment |
| Tutor | Keyword retrieval and cited excerpts | Validated model and source control |
| Authoring | Create draft courses, lessons, questions | Versioning and approval |
| People | Create fictional users, enroll | Identity and access management |
| Schedule | Create and complete sessions | Resource planning |
| Competencies | Record draft observations | Authorized assessment framework |
| Qualifications | Gated demo completion record | Legal issuance authority |
| Customers | Simulated customer-scoped metrics | Tenant isolation |
| Compliance | Findings and source registry | Evidence, independent audit |
| Analytics | Scoped results and JSON export | Server reports and retention |
| Audit | Local event history | Immutable audit and monitoring |

Roles are simulated in one browser. All records are fictional and editable. No regulatory approval is claimed. The public site must never contain sensitive information.
