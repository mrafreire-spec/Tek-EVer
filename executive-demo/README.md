# Executive demo v0.7

Civil-only prototype. Adaptive learning uses latest results for distinct question IDs per learning objective. Diagnostic covers 27 objectives, remediation selects 10 priority items, final practice uses 40 items. Aggregate simulated scores are not evidence. Limited item coverage and review status prevent claims of competence.

Protected optional live tutor uses Vercel OIDC or server-only AI_GATEWAY_API_KEY, ACADEMY_TUTOR_ACCESS_HASH and ACADEMY_TUTOR_EXPIRES. No secrets in source. Local retrieval fallback is explicitly labelled. Rate limits are instance-local, not a guaranteed global spend cap. Public course material only; no personal or restricted data. Do not use for actual flight decisions or official examinations.
